# 截图

README 里引用了下面两个文件，**文件名必须一致**，否则 GitHub 上会显示破图：

| 文件名 | 内容 | 打码 |
|---|---|---|
| `mr-comment.png` | 合并请求里 AI 评论的效果，能同时看到文件行号和评论正文 | 仓库路径、组织名、业务代码 |
| `commit-status.png` | 云效「自动化检查」里 `ai-bug-scan` 显示通过的那一栏 | 仓库名、提交说明 |

这两张是最要紧的。第一张回答「输出长什么样」，第二张回答「怎么接进云效」，很多人看完这两张才决定要不要往下读。

下面几张可选，能给文档加不少说服力：

| 文件名 | 内容 |
|---|---|
| `webhook-config.png` | 云效 webhook 新建页，能看出勾了哪些事件 |
| `webhook-delivery.png` | webhook 推送记录，状态 200 |
| `wecom-notify.png` | 企业微信群里的通知消息 |
| `helm-install.png` | `helm upgrade --install` 成功后的输出 |

## 建议

- 宽度压到 1200px 以内，否则 README 里会撑得很宽
- PNG 或 WebP 都行，单张控制在 300KB 以内
- 打码用纯色块，别用模糊——模糊过的文字有时候还能认出来
